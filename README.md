# PROJET

Projet scolaire ayant pour objectif de tester différents interpolateurs (krigeage, linéaire, méthode des splines).

# ASPECTS TECHNIQUES

Les algorithmes sont développés en Python, et les cartes sont créées via la bibliothèque Matplotlib.

# VISUALISATION

Les cartes produites sont visibles directement dans le dossier Donnees_crees/Cartes/, mais l'exécution des codes de chaque étape permet d'obtenir les mêmes rendus.
